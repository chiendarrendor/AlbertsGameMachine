# AlbertsGameMachine

Before doing anything else in this repo, read `.claude/MEMORY.md` and treat its contents as
established project memory — it's the index into everything already known about this project
(architecture, per-component notes, game-specific details, build environment, and the roadmap).
Follow its pointers to the other files in `.claude/` as needed for the task at hand.

Also read `.claude/TODO.md` for the live project-wide to-do list, and, if working on
MerchantOfVenus specifically, `.claude/MerchantOfVenus/IMPLEMENTATION_STATUS.md` for that game's
current implementation status.

This `.claude/` directory is the durable, git-tracked knowledge base for this project — it
travels with the repo across machines (this is intentional: Albert works from both a Windows/
MSYS laptop and a Linux EC2 instance). Keep it updated as understanding changes: correct it when
something here turns out to be stale or wrong, and add to it the way the rest of it was built —
as new architecture, decisions, or resolved questions come up in conversation.
